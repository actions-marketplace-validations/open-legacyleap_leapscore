# LeapScore 1.0.2 — release notes

Metadata-only release: it renames the GitHub Marketplace listing and nothing else.

`1.0.1` was published under `name: "LeapScore local scan"`, which GitHub slugified to
`leapscore-local-scan` — a third name for an artifact the package, the command, and the
release identity already call `leapscore-scan`. `1.0.2` sets the root `action.yml` name to
`LeapScore scan`, so the listing slug, the npm package, and the CLI command finally agree,
and rewords the description so the local-only scope survives once the name stops carrying
it:

> Checkout-first local scan: grades the checked-out working tree, with no clone and no
> token.

Scanner, scoring, rubric, report-envelope, CLI, and Action behavior are unchanged. No
input, output, `branding`, or `runs` key changed, and the Action is still checkout-first
and local-only: no `--repo` input, no remote-scan lane, no token.

## Identity

The package version is still the build stamp, so the sealed `engine_version` moves from
`1.0.1` to `1.0.2` and every `score_fingerprint` changes with it. The fingerprint era is
unchanged (`fingerprint_version: 3`). Baseline deltas keep working: engine identity is a
recorded, non-blocking comparability input, so rows still compare across `1.0.1` and
`1.0.2`; only re-seal a `1.0.0` baseline, which is a different fingerprint era.

## Install

```bash
npx leapscore-scan . --out leapscore-report
```

## Action

```yaml
- uses: actions/checkout@v5
  with:
    fetch-depth: 0
- uses: open-legacyleap/leapscore@v1
  with:
    path: .
    fail_under_band: moderate
```

## Marketplace

The listing publishes from `v1.0.2` at
<https://github.com/marketplace/actions/leapscore-scan>. `1.0.1`'s Marketplace flag is
retired in the same operator session, so exactly one listing exists and **no
Marketplace-visible version remains below `1.0.2`**. Retiring the flag is
presentation-only: `@v1.0.1` and the moving `@v1` keep resolving, because the destination
is the same committed artifact.

Publishing is an operator step in the release UI; the release workflow creates the release
without a Marketplace flag.
