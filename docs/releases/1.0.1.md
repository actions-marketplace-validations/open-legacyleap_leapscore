# LeapScore 1.0.1 — release notes

Patch release for the GitHub Marketplace listing. `1.0.0` shipped a 142-character
`action.yml` description, and Marketplace requires fewer than 125 characters, so
`1.0.1` shortens it to:

> Checkout-first LeapScore scan: grades the checked-out working tree locally, with no
> clone and no token.

There are no scanner, scoring, rubric, report-envelope, CLI, or Action behavior changes.

## Identity

The package version is still the build stamp, so the sealed `engine_version` moves from
`1.0.0` to `1.0.1` and every `score_fingerprint` changes with it. The fingerprint era is
unchanged; re-seal a `1.0.0` baseline before comparing deltas.

## Install

```bash
npx leapscore-scan . --out leapscore-report
```

## Action

```yaml
- uses: actions/checkout@v5
  with:
    fetch-depth: 0
- uses: open-legacyleap/leapscore@v1
  with:
    path: .
    fail_under_band: moderate
```
